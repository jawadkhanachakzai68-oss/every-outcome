# Every Outcome: check my work

Code, raw results and claims tables for the YouTube channel **Every Outcome**.
Every video has a folder. Inside each folder:

- `CLAIMS.txt`: every number in the video, with where it came from (my own code or a published source)
- the code, and a short `README.md` that says how to run it
- `code_output.txt`: what the code printed

| Folder | Video |
| --- | --- |
| `08-catan-opening-strategies` | The Best Catan Opening Strategy, Tested in 27,500 Games |
| `09-rubiks-cube-gods-number` | Rubik's Cube God's Number Is 20. How Was It Proved? |

More folders are added with each new video. If you find a mistake, open an issue and I will check it and correct the video description.
